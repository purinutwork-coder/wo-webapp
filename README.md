# wo-cf — เครื่องมือวัดของกองที่ 0 **ไม่ใช่โครงของระบบจริง**

> **โฟลเดอร์นี้ไม่ใช่จุดเริ่มต้นของระบบบน Cloudflare** · มันคือเครื่องวัดที่ใช้ตอบคำถาม
> ที่ยังไม่รู้คำตอบ ก่อนตัดสินใจว่าจะย้ายหรือไม่ย้าย · โค้ดในนี้ไม่มีชั้นสิทธิ์ ไม่มีชั้นตัวตน
> ไม่มีการตรวจข้อมูลนำเข้า และไม่เคยถูกออกแบบให้มี · **ห้ามเอาไปต่อยอดเป็นของจริง**
> ให้เริ่มโครงของจริงใหม่ตามแผนกองที่ 1

Worker ที่ deploy จากโฟลเดอร์นี้ **ถูกลบทิ้งไปแล้ว** เมื่อ 30-09-2026 พร้อมความลับทั้งสามตัว
ตามเงื่อนไขที่เจ้าของระบบตั้งไว้ว่า *"ของชั่วคราวที่ยังกดได้คือกับดักที่รอคนเผลอ"*
สิ่งที่เหลือไว้คือวิธีวัด เพื่อให้วัดซ้ำได้ด้วยวิธีเดิมตอนย้ายจริง

## คำถามที่มันตอบ และคำตอบที่วัดได้

| | วัดได้ |
|---|---|
| **ความเร็วจากไทยไปฐานข้อมูล** | อ่านเรียงกัน 6 ครั้ง **242 ms** เทียบกับ Apps Script **2,271 ms** — เร็วขึ้น 9.4 เท่า · คำขอเดียว 40 ms เทียบกับ 423-485 ms |
| **รหัสผ่านเดิมใช้ต่อได้ไหม** | ได้ · Worker คำนวณค่าเดียวกันตัวต่อตัว ไม่มีใครต้องตั้งรหัสใหม่ · ราว **30 ms ต่อการตรวจหนึ่งครั้ง** เพดานหมดที่ 8-16 ครั้งต่อคำขอ |
| **ออก PDF ภาษาไทยได้ไหม** | ได้ · **8.2 วินาทีต่อฉบับ** · วรรณยุกต์บนสระบนวางถูก ไม่มีกล่องสี่เหลี่ยม |

ทุกตัวเลขวัดจาก colo **BKK** (กรุงเทพ)

## ข้อควรรู้ที่ติดมากับการวัด — อ่านก่อนวัดซ้ำ

**นาฬิกาในตัว Worker วัดเวลาคำนวณของตัวเองไม่ได้** · `Date.now()` ไม่เดินเลยระหว่าง
การคำนวณที่ไม่มี I/O ซึ่งเป็นมาตรการกัน Spectre ของแพลตฟอร์ม · Worker รายงานกลับมาว่า
ใช้เวลา `0 ms` ทั้งที่วน SHA-256 ห้าพันรอบ · ทางที่ใช้ได้คือให้ทำงานซ้ำ K ครั้งแล้ววัดจาก
ฝั่งผู้เรียก เวลาเครือข่ายเท่ากันทุกครั้งจึงตัดกันหมด ส่วนต่างที่เหลือคือเวลาคำนวณล้วน

**ต้องนับเฉพาะคำขอที่ได้ 200** · คำขอที่ชนเพดาน CPU ตอบกลับ **เร็วกว่า** คำขอที่สำเร็จ
ถ้าเอาเวลามาเฉลี่ยรวมกันจะได้ตัวเลขที่ดูดีกว่าความจริง — เคยเกือบรายงานผิดมาแล้วครั้งหนึ่ง

**ชนเพดาน CPU หนึ่งครั้งแล้วพาทั้งตัวลง** · หลังจากนั้นคำขอถัดไปทุกคำขอตอบ 503
แม้เป็นงานเบาที่สุด จนกว่าจะเริ่มใหม่ · ไม่ใช่ตายเฉพาะคำขอที่หนัก

**คำขอแรกของแต่ละ isolate ใช้ 773 ms** (จับมือ TLS + DNS) แล้วที่เหลือ 40 ms

**เบราว์เซอร์ค้างอยู่หลังปิด** · ยิงออก PDF สามครั้งติดกัน สองครั้งหลังได้ 500
เพราะชนเพดาน 3 ตัวพร้อมกันของแผนฟรี · ถ้าหลายคนกดพิมพ์พร้อมกันจะมีคนไม่ได้ไฟล์

**ฟอนต์ไทยที่ได้คือ `Loma`** ไม่ใช่ตัวที่ขอไป (`Noto Sans Thai`, `Sarabun`) ·
เครื่องเรนเดอร์ถอยไปใช้ตัวที่ตัวเองมีโดยไม่บอกใคร · ฟอนต์ถูกฝังและตัดเฉพาะตัวที่ใช้มาใน
ไฟล์ (`FontFile2` หกชุด) **เครื่องปลายทางจึงไม่ต้องมีฟอนต์ไทย** แต่ถ้าอยากคุมหน้าตา
ให้เหมือนแม่แบบเดิม ต้องส่งไฟล์ฟอนต์ไปเองผ่าน `@font-face`

## เงื่อนไขที่ใช้ตอนวัด

- **anon key เท่านั้น** ไม่เคยมี service_role อยู่ใน Worker ตัวนี้
- ทุกคำขอไปฐานข้อมูลได้ **`http 401` พร้อม `42501 permission denied`** ซึ่งเป็นรหัสของ
  Postgres เอง แปลว่าเดินทางครบเส้นทางแล้วถูกปฏิเสธที่ประตู GRANT
  **ไม่ใช่การวัดเส้นทางเต็มรูปแบบ** — ที่ขาดคือการอ่านแถวกับแปลงผล
- ทุกทางมีด่านรหัสลับ 64 ตัวอักษร ปิดตายเมื่อยังไม่ได้ตั้งรหัส และเทียบแบบใช้เวลาเท่ากัน
- ไม่เคยเขียนอะไรลงฐานข้อมูล ไม่มีเส้นทางไหนเขียนได้

## ถ้าจะวัดซ้ำ

```
npm install
npx wrangler login
npx wrangler deploy
npx wrangler secret put PROOF_TOKEN     # สุ่มยาว ๆ ต้องมีก่อน ไม่งั้น Worker ปิดตาย
npx wrangler secret put SUPABASE_URL
npx wrangler secret put SUPABASE_KEY    # anon key
curl -H "x-proof-token: <รหัส>" https://<ชื่อ>.workers.dev/speed
```

**ห้ามใส่กุญแจลงไฟล์ในโฟลเดอร์นี้** · `.dev.vars` ถูก `.gitignore` กันไว้
และเมื่อวัดเสร็จให้ลบ Worker กับความลับทิ้งทุกครั้ง
